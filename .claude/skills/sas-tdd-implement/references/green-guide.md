# GREEN 단계 가이드 (위임용)

GREEN(테스트를 통과시키는 최소 구현)을 위임할 때 위임 대상(Codex·에이전트)에 그대로 전달한다.

- 테스트 파일은 수정하지 않는다. P3 recipe(시각·UX 판정용)가 있으면 실행·판정하지 않고 그대로 둔다.
- 테스트를 통과시키는 데 필요한 최소한만 구현한다. 사양에 없는 기능을 추가하지 않는다.
- 새 패키지·도구를 설치하지 않는다 — RED 단계에서 이미 준비돼 있다.
- 변경할 때마다 대상 테스트를 다시 돌려 통과를 확인한다. 마무리 검증도 관련 범위 테스트까지만 돌리고, 전체 build·lint·전체 테스트는 돌리지 않는다.
- 범위 확장, 지시와 다르게 수행해야 하는 상황, 대안 제안, 진행 자체가 불가능한 경우, 그 밖의 특이사항을 만나면 우회·편법으로 넘기지 않고 그 지점에서 멈춰 보고한다.
- 코드와 주석은 plan·research 같은 임시 작업 문서를 참조하지 않는다. 이 문서들은 작업이 끝나면 아카이빙되거나 삭제되어 참조가 끊긴다. 배경이 그 문서에만 있어 코드만으로 복원되지 않으면 문서를 가리키는 대신 배경을 주석에 옮겨 적는다. 공식 문서·표준 스펙처럼 공인된 출처는 링크로 참조할 수 있다.
