# 메모리 관리 (항상 실행)

자동 메모리(`~/.claude/projects/<프로젝트 슬러그>/memory/`)와 `docs/memory`의 점검·관리는
`sas-memory-manager` 에이전트가 한다. 이 스킬은 에이전트를 부르고, 확인이 필요한 판정을
사용자에게 전달하고, 승인 결과를 돌려주는 일만 한다. 무엇을 남기고 지울지는 에이전트의
판단이다.

## 호출

컨펌 뒤 Agent 도구로 호출한다. 입력: 저장소 루트, 자동 메모리 디렉터리, `docs/memory` 경로,
그리고 ①을 골랐으면 완료 PRD 경로들.

| 상황         | 요청                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| ① 선택 안 함 | "두 저장소를 점검해 관리해 달라. 판정을 먼저 돌려주면 승인된 것을 이어서 보낸다"         |
| ① 선택       | 위에 더해 "이 PRD의 결정 중 남길 것을 메모리에 편입해 달라. PRD 폴더 이동은 스킬이 한다" |

③ tmp 정리는 이 호출과 동시에 진행한다.

## 확인 왕복

서브에이전트는 사용자에게 직접 묻지 못한다. 에이전트가 확인이 필요한 항목에 번호를 붙여
돌려주고 멈추면, 이 스킬이 AskUserQuestion으로 사용자에게 확인받고 승인 항목을 같은 에이전트에
이어 보내 적용하게 한다. 확인할 항목이 없으면 그 결과를 그대로 보고한다.

## 결과 보고

에이전트가 돌려준 결과를 보고 표에 넣는다(통폐합·갱신·삭제·편입 건수와 보류 항목). 저장소 안
변경(`docs/memory`)은 git 상태로 보고하고 커밋하지 않는다.
