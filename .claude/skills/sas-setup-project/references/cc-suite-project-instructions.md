# cc-suite 프로젝트 지시문

`.cc-suite.md` 의 Project-Specific Instructions 에 반드시 있어야 하는 문구를 모은 목록이다. `sas-setup-project` 2번 단계가 `/cc-suite:init` 호출 뒤 이 문구들이 있는지 확인하고, 없으면 채워 넣는다.

새로 필요한 지시가 생기면 이 파일에 항목을 추가한다. `sas-setup-project` 본문은 고치지 않아도 된다.

---

Codex 세션에 context7(라이브러리·프레임워크 문서 조회), exa(웹 검색·원문 열람), serena(코드 심볼 탐색), GitHub MCP(저장소 코드·이슈·릴리스 조회) 같은 도구가 연결돼 있으면 적극 활용해 정확도를 높이고 불필요한 탐색 비용을 줄인다. 이 외에 다른 MCP 도구가 가용하고 과제에 적합하면 그것도 최대한 활용한다. 어느 도구든 가용하지 않으면 그 사실을 결과 보고에 명시한다.
