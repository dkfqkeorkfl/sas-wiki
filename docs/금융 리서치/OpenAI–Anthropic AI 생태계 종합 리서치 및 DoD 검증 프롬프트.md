# OpenAI–Anthropic AI 생태계 종합 리서치 및 DoD 검증 프롬프트

## 0. 작업 목적

OpenAI/ChatGPT와 Anthropic/Claude를 중심으로 형성된 현재 AI 산업의 **투자·지분·클라우드·GPU/TPU·데이터센터·장기 구매계약·보증·금융 구조**를 종합적으로 조사하고 하나의 장기 보관용 리서치 문서로 정리한다.

단순히 “OpenAI 진영 vs Anthropic 진영”이라는 이분법적 구도를 만드는 것이 목적이 아니다.

실제로는 Microsoft, Amazon, Google, NVIDIA, SoftBank, Oracle, CoreWeave, Broadcom, 각종 데이터센터 사업자, 은행·사모신용·SPV 등이 복수의 AI 기업과 동시에 연결되어 있으므로 다음을 명확하게 표현해야 한다.

- 누가 누구에게 직접 투자했는가
- 투자 규모는 얼마인가
- 지분 투자와 단순 상업 계약을 구분할 수 있는가
- 누가 누구의 클라우드 또는 컴퓨팅을 구매하는가
- 장기 구매·임대 약정 규모는 얼마인가
- GPU/TPU 및 데이터센터 공급자는 누구인가
- 데이터센터 건설비를 누가 금융조달하는가
- 누가 임대료·컴퓨팅 구매·전력비·잔존가치 등을 보증하거나 백스톱하는가
- AI 회사에 투자한 기업이 다시 해당 AI 회사로부터 매출을 얻는 순환 구조가 어느 정도 존재하는가
- 이것을 '순환출자'라고 부르는 것이 정확한지, 아니면 circular financing / vendor financing / circular AI trade에 더 가까운지
- 닷컴버블 또는 IT버블과 구조적으로 무엇이 비슷하고 무엇이 다른가
- 각 관계가 실제 확정 계약인지, 발표된 계획인지, 언론 보도상 협의 단계인지를 구분할 수 있는가

최종 결과물은 다른 검증 프롬프트를 요구하거나 “추가 검증이 필요하다”고 끝내는 메모가 아니라, **그 자체로 완결된 리서치·보고서**여야 한다.

# 1. 전체 에이전트 구조

다음 3단계 구조로 작업한다.

## Agent A — 원칙러 / DoD 설계자

역할:

- 연구를 시작하기 전에 Definition of Done(DoD)을 설계한다.
- 정확성, 출처, 수치 일관성, 관계 누락, 최신성, 표현 정확성을 검증하기 위한 평가기준을 만든다.
- 메인 에이전트가 반드시 조사해야 할 엔티티와 관계를 사전에 정의한다.
- 최종 결과물을 직접 작성하지 않는다.
- 연구 결과를 유도하는 방향으로 결론을 미리 정하지 않는다.

## Agent B — 메인 리서치 에이전트

역할:

- 아래 제공된 기존 대화의 논점과 가설을 출발점으로 삼는다.
- 모든 중요 사실을 독립적으로 조사한다.
- 과거 대화의 숫자나 결론을 사실이라고 전제하지 않는다.
- 최신 정보 기준으로 하나의 종합 리서치 문서를 작성한다.
- 관계도, 표, 설명, 위험 분석을 모두 포함한다.

## Agent C — 원칙러 / DoD 평가자

역할:

- Agent A가 작성한 DoD에 따라 Agent B의 결과물을 항목별로 평가한다.
- 누락, 오래된 정보, 잘못된 관계, 숫자 혼동, 출처 부족 등을 찾는다.
- 부족한 항목이 있으면 필요한 부분만 추가 조사하거나 수정한다.
- DoD를 만족할 때까지 최종 문서를 갱신한다.

최종 사용자는 Agent C의 평가 과정이 아니라 **수정 완료된 최종 리서치 문서**를 받는다.

# 2. Agent A — DoD 설계

Agent A는 연구 전에 최소 다음 DoD를 설계한다.

## 2.1 사실 검증 DoD

중요 관계와 금액은 가능한 한 다음 기준을 만족해야 한다.

### Tier 1 — 매우 높은 신뢰도

다음 중 하나 이상:

- 회사 공식 발표
- SEC 또는 이에 준하는 공식 공시
- 회사 투자자관계(IR)
- 금융기관 공식 문서
- 공식 계약 설명

그리고 가능하면 독립적으로 다음 중 하나를 추가한다.

- Reuters
- Financial Times
- Wall Street Journal
- Bloomberg
- CNBC 등 주요 경제매체

### Tier 2 — 높은 신뢰도

공식 발표가 없는 비공개 계약·금융 구조의 경우:

- 최소 두 개의 독립적인 신뢰도 높은 언론
- 또는 한 개의 최상위 언론 + 구체적인 계약/금융 관계를 설명하는 추가 자료

### Tier 3 — 추정 또는 협상

다음의 경우 명확하게 별도 표시한다.

- 협상 중
- proposed
- considering
- in talks
- could
- expected
- reported
- sources familiar with the matter

이것을 확정 계약처럼 서술하지 않는다.

# 3. 반드시 구분해야 하는 돈의 종류

모든 숫자는 다음 중 어떤 종류인지 표시한다.

1. 지분 투자액
2. 누적 지분 투자액
3. 기업가치 / valuation
4. 특정 투자자의 보유 지분 가치
5. 클라우드 구매 약정
6. GPU/TPU 구매 약정
7. 데이터센터 임대 약정
8. 프로젝트 총사업비
9. 프로젝트 파이낸싱
10. 은행 대출
11. 보증 한도
12. 지급보강 / guarantee / backstop
13. 잔존가치 보장
14. 전력 구매 또는 전력비 보증
15. 조건부 투자 약정
16. 투자 가능 최대치
17. 이미 집행된 금액과 향후 예정 금액

절대로 서로 다른 성격의 숫자를 합산하여 “총 투자액”처럼 표현하지 않는다.

## 4.1 OpenAI / ChatGPT 측

기존 대화에서 언급된 주요 관계:

### Microsoft

- OpenAI의 핵심 전략 투자자
- OpenAI와 Azure 간 장기적인 클라우드·컴퓨팅 관계
- OpenAI 구조 재편 후 Microsoft가 상당 규모의 경제적 지분을 보유한다는 발표
- 기존 대화에서는 약 $135B의 투자 가치와 약 27%라는 숫자가 언급됨
- 이 숫자의 정확한 기준:
  - fully diluted인지
  - 경제적 지분인지
  - voting right와 다른지
  - 어떤 시점의 valuation인지
  확인할 것

### Amazon / AWS

기존 대화에서는 2026년 이후:

- Amazon이 OpenAI에도 대규모 직접 투자를 발표했다는 내용이 언급됨
- 약 $50B 수준이라는 숫자가 등장함
- 이것이:
  - 직접 지분 투자인지
  - 투자 약정 최대치인지
  - 현금 집행액인지
  - AWS 사용계약과 연결된 것인지
  정확히 구분할 것

### NVIDIA

기존 대화에서:

- OpenAI에 대규모 직접 투자
- 약 $30B라는 숫자가 언급됨
- 동시에 GPU 공급자
- 향후 추론 컴퓨팅 또는 데이터센터 인프라 공급과 연결

따라서 NVIDIA → OpenAI 투자와 OpenAI → NVIDIA GPU 구매의 양방향 경제관계를 분석할 것.

### SoftBank

기존 대화에서:

- OpenAI의 주요 대규모 투자자
- 데이터센터 프로젝트 및 SB Energy 같은 관계가 언급됨
- 투자 규모와 데이터센터 개발 역할을 분리해 조사할 것

### Oracle

기존 대화에서:

- OpenAI의 대규모 컴퓨팅·데이터센터 파트너 중 하나로 언급됨
- Stargate 또는 기타 OpenAI 인프라와 어떤 계약관계인지 조사
- Oracle이 단순 클라우드 공급자인지, 투자자인지, 프로젝트 지분 참여자인지 구분

### CoreWeave

- OpenAI용 GPU 컴퓨팅 제공
- 장기 사용계약 및 데이터센터 금융과 연결될 가능성
- NVIDIA와 CoreWeave 간 투자·GPU 공급·매출 구조도 참고

# 5. Anthropic / Claude 측

## 5.1 Amazon / AWS

기존 대화에서 매우 중요한 축으로 다룸.

언급된 내용:

- Amazon의 Anthropic 기존 누적 투자
- 과거 약 $8B
- 이후 추가 투자로 현재 $13B가 되었다는 내용
- 향후 조건부로 최대 $20B 추가 가능하다는 내용
- 따라서 잠재적으로 훨씬 큰 투자 관계
- Anthropic이 AWS 기술에 향후 10년간 $100B 이상을 지출한다는 구매 약정이 언급됨
- Trainium과 Graviton 등이 포함됨

반드시 확인:

- 집행 완료액
- 추가 약정액
- 조건부 추가 투자
- 총 투자 가능액
- AWS 구매 약정
- 기간
- Anthropic의 AWS 사용 의무
- Amazon의 preferred cloud provider 관계 여부
- 다른 클라우드와 병행하는지

---

## 5.2 Google / Alphabet

기존 대화에서 중요한 정정사항.

Google은 Anthropic의:

- 직접 지분 투자자
- Google Cloud 제공자
- TPU 공급자
- 데이터센터 금융 및 지급보강 관계자

로 언급됐다.

기존 대화 중 등장한 숫자:

- 초기 수십억 달러 투자
- 이후 추가 투자
- 2026년에 즉시 $10B
- 성과조건 등을 충족할 경우 추가 최대 $30B
- 잠재적으로 신규 투자 $40B 규모

이 숫자를 반드시 최신 자료로 재검증한다.

또한 다음을 별도로 조사:

- Google과 Anthropic의 총 누적 지분투자
- Google Cloud 계약
- TPU 사용계약
- Broadcom 관계
- Google의 데이터센터 보증
- Anthropic이 Google 인프라를 사용하면서도 AWS도 함께 사용하는 구조

### 중요한 정정사항

기존 대화에서 사용자는:

> “Google과 Microsoft가 두 곳 모두 투자한 것 아니냐”

고 문제를 제기했다.

재검토 과정에서 잠정적으로:

- Microsoft → OpenAI : 직접 투자 있음
- Microsoft → Anthropic : 직접 투자 있음
- Google → Anthropic : 직접 투자 있음
- Google → OpenAI : 직접 지분 투자는 확인되지 않음

이라는 결론에 도달했다.

이 부분은 특히 강하게 다시 검증한다.

Google이 OpenAI에:

- 직접 지분 투자
- 펀드를 통한 간접 투자
- 데이터센터 프로젝트 투자
- 단순 상업 계약

중 무엇이라도 있는지 혼동하지 않는다.

# 6. Microsoft → Anthropic 관계

이전 첫 번째 정리에서는 이 관계를 단순한 “클라우드 접점”처럼 표현해 오류가 있었다.

이후 정정 과정에서:

- Microsoft가 Anthropic에 최대 약 $5B 직접 투자
- Anthropic이 Azure 컴퓨팅 약 $30B 구매
- 최대 1GW 추가 컴퓨팅 용량 계약

이라는 내용이 확인 대상으로 등장했다.

반드시:

- Microsoft 공식 발표
- Anthropic 공식 발표
- 독립 언론

중 최소 두 종류의 자료로 교차확인한다.

그리고 이것이 의미하는 바를 분석한다.

즉:

Microsoft는 OpenAI의 핵심 주주이면서 동시에 Anthropic에도 투자하고 Anthropic을 Azure 고객으로 확보한다.

따라서 Microsoft를 단순히 “OpenAI 진영”이라고만 부르는 것은 현재 상황에서는 부정확할 수 있다.

---

# 7. NVIDIA → Anthropic 관계

기존 대화에서:

- NVIDIA가 Anthropic에도 최대 약 $10B 투자
- Microsoft와 함께 발표
- 동시에 NVIDIA는 OpenAI에도 대규모 투자

라는 내용이 등장했다.

따라서 NVIDIA는:

> 양쪽 AI 모델 기업에 자본을 공급하면서 동시에 GPU 공급자로 매출을 얻는 기업

이라는 구조가 될 가능성이 있다.

확인해야 할 것:

- 직접 지분 투자 여부
- 투자액
- 집행 완료인지 약정인지
- Anthropic이 실제 NVIDIA GPU를 얼마나 사용하는지
- AWS Trainium / Google TPU와 경쟁 또는 병행되는지

# 8. “진영” 개념을 다시 정의할 것

잘못된 단순화 예:

- OpenAI = Microsoft 진영
- Anthropic = Amazon + Google 진영

# 9. 데이터센터 보증 구조

이 연구에서 특히 중요하게 다뤄야 한다.

## 9.1 NVIDIA와 OpenAI 관련 데이터센터 보증

기존 대화에서 다음 내용이 등장함:

- NVIDIA가 OpenAI 관련 오하이오 대규모 데이터센터 프로젝트의 금융을 지원하기 위해
- 약 $250B 규모의 보증 또는 backstop을 제공하는 방안을 논의하고 있다는 보도
- 프로젝트 총규모가 $500B 이상일 가능성도 언급됨

중요:

이 내용은 당시 **공식 확정 계약이 아니라 언론의 협의 보도**로 분류했다.

재조사하여 현재 상태를 확인한다.

- 협상 중인지
- 계약 체결됐는지
- 규모가 바뀌었는지
- 실제 NVIDIA의 법적 지급 의무는 무엇인지

“$250B 투자”라고 잘못 표현하지 않는다.

# 10. Google–Anthropic 데이터센터 금융 구조

기존 대화에서 가장 복잡하고 중요한 구조 중 하나.

# 12. 보증의 종류를 구체적으로 설명할 것

‘보증’이라는 말을 하나로 뭉뚱그리지 않는다.

가능한 형태:

### Lease Guarantee
AI 기업이 임대료를 지급하지 못할 경우 후원사가 대신 지급.

### Backstop
특정 금융조건이 충족되지 않을 경우 자금 또는 지급능력을 보강.

### Take-or-pay / Minimum Purchase
사용량과 관계없이 최소 컴퓨팅 사용료 지급.

### Residual Value Guarantee
GPU·TPU 또는 장비의 중고가치가 특정 수준 이하로 내려갈 경우 공급자가 일부 손실을 부담.

### Power Payment Guarantee
전력 구매 또는 전력비 지급 의무를 제3자가 보강.

### Lease Assumption
주 임차인이 디폴트할 경우 다른 기업이 임대계약을 인수.

### Termination Payment
계약 파기 시 개발사 또는 채권자에게 일정 금액 지급.

각 프로젝트에서 어떤 구조인지 확인하고 정확한 용어를 사용한다.

# 13. 순환출자 vs 순환금융

사용자가 특히 관심을 가진 부분이다.

기존 대화에서는 다음과 같은 구조를 논의했다.

예:

1. Microsoft / Amazon / NVIDIA / Google 등이 AI 기업에 투자
2. AI 기업은 투자 받은 자금으로
   - Azure
   - AWS
   - Google Cloud
   - NVIDIA GPU
   - TPU
   - 데이터센터 용량
   등을 구매
3. 공급자는 그 지출을 매출로 인식
4. 공급자의 매출과 기업가치가 증가
5. 공급자는 다시 AI 기업이나 데이터센터 프로젝트에 투자
6. AI 기업의 장기 컴퓨팅 계약은 프로젝트 파이낸싱의 근거가 됨
7. 은행·SPV가 이를 기반으로 데이터센터 건설 자금을 공급
8. 필요하면 hyperscaler 또는 GPU 회사가 지급보강
9. 이 구조를 통해 다시 더 많은 GPU·데이터센터 구매가 가능

최종 문서에서는 이를 그림 또는 흐름도로 표현한다.

다만 법률·회계적으로 한국 재벌식:

> A → B → C → A

지분 순환출자와 동일하다고 표현하지 않는다.

보다 정확한 후보 용어:

- circular financing
- vendor financing
- circular AI trade
- ecosystem financing
- supplier-financed demand
- customer financing
- project finance backed by compute contracts

각 용어의 차이도 간략히 설명한다.

# 14. 닷컴버블 / IT버블과 비교

사용자는 현재 AI 생태계가 과거 IT 버블과 유사한지 관심을 보였다.

최종 문서에서 객관적으로 비교한다.

## 유사점 후보

- 미래 수요를 전제로 매우 큰 CAPEX 선집행
- 고객과 공급자가 서로 투자·구매 관계
- 수요가 미래 성장률을 전제로 금융화됨
- 장기계약이 차입 근거로 사용
- 인프라 과잉건설 위험
- 매우 빠른 기업가치 상승
- 시장 전체가 소수 기술기업에 집중
- 신규 자본이 다시 기술 공급자의 매출로 돌아가는 구조

## 차이점 후보

- Microsoft, Amazon, Google, NVIDIA 등은 이미 대규모 현금흐름을 보유
- 클라우드 사업은 이미 수익을 발생
- AI 서비스도 실제 매출을 창출
- GPU·데이터센터·전력설비는 실물자산
- 기업 고객의 AI 사용도 존재
- 단순 웹사이트 트래픽만으로 valuation을 설명했던 닷컴 초기 기업과는 다름

그러나 다음 위험은 그대로 존재:

- AI 추론 비용 급락
- 알고리즘 효율화
- 모델 압축
- 더 적은 GPU로 같은 성능 구현
- 데이터센터 공급과잉
- 전력망 지연
- GPU/TPU 조기 노후화
- 임차인 집중
- AI 기업의 현금흐름 부족
- 장기 계약 해지 또는 재협상
- off-balance-sheet obligation
- 대규모 lease commitment

따라서 최종 결론을:

“버블이다 / 아니다”

식으로 단정하지 않는다.

대신:

> AI 수요 자체의 실재성과 별개로, 인프라 투자속도·금융레버리지·장기 계약규모가 실제 AI 현금흐름보다 얼마나 앞서 있는가

를 핵심 평가 기준으로 삼는다.

하나라도 4점 이하이면 해당 부분을 다시 조사한다.

# 23. 최종 출력 원칙

DoD 평가 과정이나 내부 토론을 최종 사용자에게 장황하게 노출하지 않는다.

최종 출력은 다음이어야 한다.

> **완성된 AI 투자·인프라 생태계 리서치 보고서**

필요한 정정은 이미 반영된 상태여야 한다.

문서 말미에만 짧게:

- 조사 기준일
- 공식자료 수
- 주요 언론자료 수
- 아직 협상 단계인 핵심 거래

를 표시한다.

# 24. 연구 태도

절대로 사용자가 이전에 가진 가설에 맞춰 결과를 만들지 않는다.

특히 다음 결론을 미리 정하지 않는다.

- AI는 버블이다
- AI는 버블이 아니다
- OpenAI 진영이 더 강하다
- Anthropic 진영이 더 강하다
- NVIDIA의 보증은 위험하다
- Google의 보증은 안전하다

자료가 보여주는 구조를 먼저 작성하고 그 뒤 해석한다.

사실(Fact), 보도(Reported), 추론(Inference), 의견(Assessment)을 명시적으로 구분한다.

# 25. 최종 연구의 핵심 질문

이 보고서는 최종적으로 다음 질문에 명확하게 답해야 한다.

> **OpenAI와 Anthropic을 중심으로 한 현재 AI 산업에서 누가 누구에게 돈을 투자하고, 그 돈이 다시 누구의 클라우드·칩·데이터센터 매출로 돌아가며, 이 계약들을 담보로 누가 데이터센터를 금융하고, 문제가 생기면 결국 누가 손실을 부담하는가?**

이 질문에 한눈에 답할 수 있는 문서라면 작업은 완료된 것이다.
